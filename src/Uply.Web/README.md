# 🚀 WebLLMTester

Минималистичный backend на **ASP.NET Core Minimal API** для работы с локальными LLM через [Ollama](https://ollama.ai).

---

## 1. Введение

**WebLLMTester** — это учебный и утилитарный проект, который позволяет быстро поднять backend для работы с локальными языковыми моделями.  
Основные цели проекта:
- Предоставить простой API для общения с LLM.
- Дать возможность генерировать пошаговые roadmap‑планы в структурированном виде.
- Обеспечить лёгкий запуск и настройку без сложных зависимостей.

### 🔑 Ключевые особенности
- Эндпоинт `/ask` — отправка произвольного промпта в модель.
- Эндпоинт `/generate-roadmap` — генерация пошагового roadmap из конкретных задач.
- Поддержка стриминга ответов от Ollama.
- Ответы собираются в удобный JSON‑формат.

## 2. Установка зависимостей

Для запуска проекта потребуется установленный **.NET 8 SDK**.

### 🔧 Шаги установки

1. Скачайте и установите .NET 8 SDK: 👉 [Скачать .NET SDK](https://dotnet.microsoft.com/en-us/download)

2. Проверьте, что установка прошла успешно: `dotnet --version`  
   В консоли должно отобразиться установленное значение версии (например, `8.0.100`).

3. Убедитесь, что у вас есть доступ к Git для клонирования репозитория: `git --version`

## 3. Запуск проекта

После установки зависимостей можно запустить проект локально.

### 🔧 Шаги запуска

1. Перейдите в папку проекта: `cd WebLLMTester`

2. Запустите проект с помощью .NET CLI: `dotnet run`

3. После успешного запуска API будет доступно по адресу: `https://localhost:5001/swagger`

Здесь вы сможете протестировать все доступные эндпоинты через встроенный Swagger UI.

## 4. Установка Ollama и моделей

Для работы проекта требуется установленный и запущенный Ollama.

### 🔧 Шаги установки

1. Скачайте и установите Ollama: 👉 [https://ollama.ai/download](https://ollama.ai/download)

2. Проверьте, что установка прошла успешно: `ollama --version`

3. Запустите Ollama локально: `ollama serve`

4. Загрузите необходимые модели. Рекомендуемые варианты:  
   - `ollama pull llama3:8b` (Используемая) 
   - `ollama pull phi3:mini` 

5. Убедитесь, что модели доступны: `ollama list`

## 5. Примеры запросов

Ниже приведены примеры использования API для проверки работы проекта.

### 🔹 Эндпоинт `/ask`

Отправка произвольного промпта в модель:

`curl -X POST https://localhost:5001/ask -H "Content-Type: application/json" -d '{"prompt": "Объясни принцип работы Docker"}'`

---

### 🔹 Эндпоинт `/generate-roadmap`

Генерация пошагового roadmap по заданной цели:

`curl -X POST https://localhost:5001/generate-roadmap -H "Content-Type: application/json" -d '{"goalTitle": "Стать Middle Backend Developer на C#", "goalDescription": "Я уже Junior, хочу прокачаться до уровня Middle за 6 месяцев"}'`

---

### 🔹 Пример ответа

```json
{
  "roadmap": [
    {
      "id": "f1a2b3c4-d5e6-7890-abcd-1234567890ef",
      "title": "Изучить многопоточность",
      "description": "Разобраться с async/await и Task Parallel Library. Отправьте отчёт в виде скриншота кода с примерами.",
      "isCompleted": false
    }
  ]
}
```
